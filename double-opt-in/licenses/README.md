# Mitgelieferte Drittanbieter-Assets

| Asset | Verwendung | Lizenz |
|---|---|---|
| Inter (Variable, Latin-Subset) | Admin-UI, als data:-URI in `admin-ui/build/index.js` eingebettet | SIL Open Font License 1.1 — `inter-OFL-1.1.txt` |

Die Schrift wird **selbst gehostet**. Es geht kein Request an
`fonts.googleapis.com` oder einen anderen Drittanbieter. Quelle des
Font-Files ist das NPM-Paket `@fontsource-variable/inter` (Build-Zeit-
Abhängigkeit von `packages/core/admin-ui`, nicht Teil des ZIPs).
